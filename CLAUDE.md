# Instructions for agents

Before doing any work in this repository, read, in order:
1. `docs/agent-prompts/RULES.md`
2. `docs/agent-prompts/DECISIONS.md`
3. `docs/agent-prompts/CONTRACTS.md`
4. `PROGRESS.md`

Work on one phase at a time, following that phase's `BUILD.md` or `VALIDATE.md` under
`docs/agent-prompts/`. Stay inside its scope and stop to ask the human when RULES.md says to.
