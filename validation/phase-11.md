## Notes (non-blocking)
Friction a stranger following only the README would hit:
- **The README's own setup does not install the app.** README "Set up" runs `pip install -r requirements-local.txt -r requirements.txt`. Neither file contains streamlit (`grep -il streamlit requirements*.txt` -> nothing). Later the README says `make app` works. After the README's manual setup, `make app` fails (no streamlit); only `make setup` installs `app/requirements.txt`.
- **Python 3.12 is required in practice.** README says "Python 3.10+", but both the manual setup and `make setup` call `python3.12`. Without a `python3.12` binary, a stranger has to find `make setup PYTHON=...`, which only CLOUD.md mentions.
- **The README doesn't warn that `make smoke` downloads 2.9 GB.** The README's `make` paragraph lists `smoke` without the size. `make help` and CLOUD.md mention it. I reused the existing `data/` via `DATA_DIR` (checksums verified) rather than download it again.
- **The clone URL can't yet reproduce this phase.** The README and CLOUD.md clone GitHub `main`, which has no Makefile, Dockerfile or `app/` until this branch is pushed. I cloned the local branch instead.
- **Try it needs files a stranger can't get yet.** Try it needs checkpoints, and a stranger has neither `runs/` nor a Hub repo. Until publishing, only Results works outside this machine. The page says so clearly.
- **`/results` doesn't load directly.** Opening `http://localhost:7860/results` gives a Streamlit "Page not found" toast and falls back to the main page, because the default page lives at `/`. `/try-it` works. Cosmetic.
- **Streamlit shows its developer toolbar.** It includes "Deploy" and a run-status "Stop" button, because `client.toolbarMode` is not set. Cosmetic, but odd on a public showcase.
- **The container looks up its public IP on start.** With network, the startup log printed `External URL: http://<public IP>:7860`, which means Streamlit made an outbound request to find it. This is harmless for a Space, but `--browser.serverAddress` or a config would avoid it.
- **`make docker-app` listens on all interfaces.** It publishes `-p 7860:7860`, so the viewer is reachable from the LAN, not only localhost.
- **An unreachable `HF_MODEL_REPO` costs about 20 s per rerun.** Try it waits for the Hub client's 5 retries before warning, as PROGRESS Known issues says.
- **The image is large (2.75 GB).** The cause is `requirements.txt` (scipy, scikit-image, opencv, pytest, ruff …). This is already in PROGRESS Known issues.
- **My Docker build used the builder's cached layers**, so I did not measure build time. The image size differs from PROGRESS by 35 bytes (2,753,738,883 vs 2,753,738,918), which is metadata of a rebuilt image.
- **Not tested here:** `Dockerfile.gpu` (no NVIDIA GPU), real Colab, a real Hub download, and an upload through the browser.
